# AMATHE 2026 — Official Conference Website

> **3<sup>RD</sup> INTERNATIONAL CONFERENCE & AICTE SPONSORED**  
> **ADVANCES IN MODERN AGE TECHNOLOGIES FOR HEALTH AND ENGINEERING SCIENCE**  
> **10–11, Dec 2026 | PESITM, Shivamogga, Karnataka, India (HYBRID MODE)**

Official conference website for **AMATHE 2026**, built with Next.js (App Router), TypeScript, and Tailwind CSS. The website is an accurate, responsive digital representation of the official conference poster and branding.

## 💻 Tech Stack & Getting Started

Built with:
- **Framework**: [Next.js](https://nextjs.org) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

### Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the website.

### Production Build

```bash
npm run build
npm start
```
